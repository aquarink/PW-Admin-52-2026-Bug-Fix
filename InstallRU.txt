		PWAdmin 5.2 by alexdnepro
			мониторинг и управление сервером PW

Программа состоит из 2-х частей: серверной (папка server_side) и клиентской (client_side)

	Подготовка к установке:
1. Запускаем ConfigsEditor.exe и редактируем конфиги
2. Обратите внимание, что начиная с версии 5.2, пароль в файле pwadmin.conf для подключения из клиент части больше не хранится в открытом виде, можно сгенерировать хеш из клиент части, или же оставить значение пустым, тогда при первом подключении пароль впишется автоматически

	Установка серверной части:
1. Копируем файлы из папки server_side на сервер в любую папку (например /pwadmin/)
2. Выставляем права на запуск файла pwadmin
3. Пробуем запускать pwadmin 
	cd /pwadmin/
	./pwadmin start
4. Смотрим данные в консоли, при успешном запуске там будут строки примерно такого содержания
	Bind to port 1500...success
5. Если bind будет с ошибкой address already in use, значит выбранный порт занят другим процессом.
6. Путь к лог файлу с чатом сервер часть пытается прочитать из конфига к logservice (который указан в processes_config.ini)

	Установка клиентской части:
1. Запускаем файл pwadmin.exe
2. Активируем
3. При первом запуске вводим данные для коннекта к серверной части

	Краткое описание
  Автоподьем данжей производится на серверной стороне (независимо от того запущен клиент или нет), управление списком автоподъема данжей и статусом активности автоподьема производится из клиентской части. При использовании нескольких клиентов для одного сервера данные списка автоподьема будут обновляться при каждом изменении в любом из клиентов. Начиная с версии 3.14, автоподьем запускает все "упавшие" данжи одиним запросом, это экономит используемую память и время запуска. Аналогичным способом можно запустить несколько данжей из клиент части вручную (для мультивыделения используются клавиши Ctrl/Shift).
  При использовании редактора персонажей мультивыделение также работает в списке предметов. Добавить айди новых бонусов можно в файле bonusesall.txt. Структура этого файла следующая: строка с названием типа бонусов, строка с айди бонусов разделенных запятой. В названии типов бонусов допускаются следующие префиксы, которые определяют тип бонусов: ^p - бонус скорости атаки (значение высчитывается по спец формуле), ^f - для дробных чисел, ^r - бонусы заточки, ^s - бонусы шлифовки, ^e - бонусы гравировки.
  При запуске сервер часть создает следующие файлы
autoinstance.txt - список данжей для автоподьема
pwadmin.log - список действий, который можно получить из клиент части через кнопку "Получить лог событий с сервер части"
pwadmin.maxonline - файл с данными о максимальном онлайне зафиксированном в клиент части
pwadmin_process_run.log - файл с потоком данных процессов, запущенных через pwadmin
pwadmin_work.log - файл с системными сообщениями и ошибками сервер части

	Настройка processes_config.ini
  Файл состоит из секций и нескольких параметров к каждой секции, название секции соответствует названию процесса, который будет отображаться в клиент части. Если какой-либо параметр не указан - значит действия связанные с его значением будут игнорироваться либо использоваться стандартные. Можно добавлять неограниченное количество произвольных секций для добавления мониторинга нужных процессов.

  ProcessDir - полный путь к файлу с процессом, допускается использование переменной $HOME$, вместо которой будет подставлен параметр homepath из конфига pwadmin.conf. Используется при запуске процесса
  ProcessFileName - имя файла процесса. Используется для поиска процесса из списка и при запуске процесса (можно использовать регулярные выражения)
  ProcessParams - параметры запуска процесса. Используется для поиска процесса из списка и при запуске процесса
  ProcessKill - shell комманда остановки процесса. Если не указан процесс будет остановлен по его PID
  ProcessStart - shell комманда запуска процесса. Если указана будет использоваться вместо запусков с параметрами ProcessFileName и ProcessParams
  ServerProcess - запускать и останавливать процесс при запуске/остановке игрового сервера, по умолчанию 0
  StartSleep - пауза после запуска процесса, секунд
  StopSleep - пауза после остановки процесса, секунд

Остановить сервер pwadmin можно из клиента кнопкой "Остановить сервер PWAdmin", или запустив сервер часть с параметром stop
./pwadmin stop

Начиная с версии 5.0 можно делать бекапы с помощью сервер части (для запуска через crontab например)
./pwadmin backup	для создания бекапа игровой базы и базы аккаунтов
./pwadmin fullbackup	для создания полного бекапа игрового сервера
